# Imane Bouhafs

I'm an AI and data science engineer, and most of my work is in generative AI and automation. I build RAG assistants that answer from documents and cite where the answer came from, LLM tools that stay inside business rules, and n8n workflows that take repetitive tasks off people's hands. I like taking a project all the way from raw data to an app someone can actually use.

## Tools

Python, PyTorch, Transformers, LLMs, RAG, Qdrant, n8n, FastAPI, React, SQL, Docker

## Selected projects

- [RAG Assistant](https://github.com/bouhafsimane2/assistant-rag-documentation): question answering over technical maintenance documentation, with sources for every answer. Published at IEEE CyMaEn 2026.
- [AI Document Extraction](https://github.com/bouhafsimane2/Document_extraction_workflow): an n8n pipeline that reads email attachments with OCR and an LLM and stores the data in Supabase.
- [NeSyChef](https://github.com/bouhafsimane2/recipies_expert_system): a recipe assistant where an LLM reads the request and a rule engine makes sure diets and allergies are respected.
- [Emotion Detection](https://detection-emotions.streamlit.app): live demo that recognizes 8 facial emotions with ResNet18.
